# 武斗 BP 新版

固定入口：https://wudou-bp-h5.pages.dev/

Cloudflare 免费 Pages 项目 `wudou-bp-h5`，绑定独立的 `wudou-bp` Worker 的 SQLite Durable Object `Room`。旧 `budou-bp-h5` 和 `budou-bp` 部署保留稳定版，方便回退。新旧域名之间不共享房间码与身份令牌。

## 更新命令

在项目目录执行：

```powershell
npm run deploy
npm run deploy:pages
```

先更新房间 Worker，再更新 Pages；命令使用已配置的免费账号授权，无需购买域名或绑定支付卡。`public/.assetsignore` 防止 Workers 把 Pages 的 `_worker.js`、`_routes.json` 当成普通静态资源上传；Pages 仍将它们识别为后端入口与路由配置。

静态页面、头像和立绘不调用 Functions。只有 `/ws`、`/room`、`/health` 使用后端请求额度。每日 100,000 是 Functions/Workers 请求额度，Durable Objects 有自己的独立额度；HTTPS 备用轮询也会消耗后端请求。

## 验收

```powershell
node --import tsx --test tests/bp.test.ts
npm run test:catalog
npm run test:order
npm run build:pages
npm run typecheck:worker
$env:BP_BROWSER_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run test:browser
```

Cloudflare 集成测试需要先运行 Pages 与房间 Worker：

```powershell
Set-Location pages
..\node_modules\.bin\wrangler.cmd pages dev --config wrangler.jsonc --config ../wrangler.jsonc --ip 127.0.0.1 --port 8789
```

在另一终端运行：

```powershell
$env:BP_WORKER_URL='ws://127.0.0.1:8789/ws'
npm run test:cloudflare-room
```

集成测试含真实 60 秒超时检查，运行时保持服务版本不变，不要同时构建或修改触发 Wrangler 热重载的文件。公网检查改用 `wss://wudou-bp-h5.pages.dev/ws`；浏览器测试可设置 `BP_BASE_URL=https://wudou-bp-h5.pages.dev`。

浏览器自动化覆盖桌面、手机横竖屏、预览不提交、确认选择、查询、导出、剪贴板拒绝、圈名加入、刷新恢复及两类 HTTPS 备用联机；实际 vivo、微信与手机流量仍需在对应设备网络下体验。
