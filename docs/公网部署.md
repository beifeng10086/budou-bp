# 最少步骤上线：Railway

这份教程部署当前项目的 Node 服务、H5 页面和 WebSocket 房间，得到一个平台提供的固定 HTTPS 网址。无需先买域名，也无需安装 Nginx 或管理服务器。需要一个 Railway 账号；付费要求和额度以账户页面为准，不承诺永久免费。

适合先让朋友通过公网测试。Railway 为海外托管，国内不同网络以及微信内访问效果需要实测；若主要面向国内长期使用，可以再迁移到国内云服务器和已备案域名。不要把“有公网网址”理解为已经保证所有手机、所有网络都能访问。

## 1. 注册并登录

打开 https://railway.com/ 注册账号。项目需要可创建、部署服务的额度或套餐。先查看控制台中的计费信息，不需要另买数据库。

在 Windows PowerShell 中依次运行（该电脑已安装 Node.js）：

```powershell
Set-Location 'C:\Users\29851\Documents\ChatGPT\武斗bp'
npm install -g @railway/cli
railway login
```

`railway login` 会打开浏览器，让你登录自己的账号。账号密码和验证码不需要发给任何人。

## 2. 建立项目和服务

```powershell
railway init
railway add
```

`init` 按提示创建项目，例如命名为 `naruto-bp`。`add` 选择空服务（Empty Service），命名为 `bp-web`，不是数据库服务。如果出现工作区、环境或服务选择，选择刚创建的项目、默认生产环境和 `bp-web`。

## 3. 上传并部署

```powershell
railway up --service bp-web
```

等待构建及部署成功。本项目已经提供 `Dockerfile` 和 `railway.json`，平台会自动安装依赖、构建页面并启动房间服务。不要选择静态网站托管方式，也不要只上传 `dist`，否则双人房间不能工作。

仓库中的 `public/data`、`public/assets/catalog` 和 `data/catalog.sqlite` 都是已采集的资料；发布时无需重新抓取官网。`.gitignore` 排除了下载参考文件、截图、源码缓存和 `node_modules`。如果你使用其他上传方式，也应排除这些目录。

## 4. 获得固定网址

```powershell
railway domain --service bp-web
```

也可以打开 Railway 控制台，进入 `bp-web → Settings → Networking → Public Networking → Generate Domain`。

若界面询问目标端口，填写服务日志实际显示的端口。默认是 `8787`；平台提供 `PORT` 时，项目会监听该环境变量指定的端口。不要填前端开发端口 `5173`。

生成的网址类似：

```text
https://你的服务名.up.railway.app
```

这是示意地址，不是已经为你创建的网址。HTTPS 由平台提供，网页会自动连接同一域名的 WSS `/ws`，通常不需要配置 `VITE_WS_URL`。

服务和域名保留期间，重新部署可继续使用这个地址。关闭你的电脑不会关闭云端服务。不要删除服务或重新生成域名来更新代码。

## 5. 用两部手机检查

1. 手机 A 打开公网网址，创建共享房间。
2. 把邀请链接发给手机 B，B 使用移动数据打开，确认加入为 2P。
3. A 点击开始，检查 A 禁用后 B 能看到同步变化，并能完成自己的选择。
4. 检查忍者头像、秘卷、通灵和结果图保存。

`网址/health` 应返回 `{"ok":true,"rooms":...}`。打不开时，先检查控制台部署状态和域名目标端口；首页能开但房间失败时，检查是否部署的是 Node 服务，并确认没有设置错误的 `VITE_WS_URL`。

## 后续更新

在同一项目目录修改后运行：

```powershell
railway up --service bp-web
```

无需换链接。更新官网资料时先运行 `npm run data:sync -- --refresh`，然后部署；云端 Docker 构建会包含更新后的数据和图片。

## 当前版本的运行限制

- 保持单副本；`railway.json` 已设置为 1。当前房间在进程内存中，多副本会造成两人可能进入不同实例。
- 重新部署、进程重启会清空房间；当前代码在双方均断线时也会清除房间。SQLite 保存的是资料库，不是房间进度。
- 手机切后台、刷新后的身份恢复尚未完善，公网测试版不能承诺断线续局。结束一场后再部署更新。
- 不启用服务休眠（如控制台提供 Serverless/App Sleeping 选项）。实际运行和流量会计费，以平台账户显示为准。
