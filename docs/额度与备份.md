# 免费额度与价格

Cloudflare 官方价格核查于 2026-10-13：

| 资源 | 免费版 | Workers 付费版 |
| --- | --- | --- |
| Workers / Pages Functions 请求 | 100,000 次/天 | 10,000,000 次/月；超出 $0.30/百万次 |
| CPU 时间 | 每次调用受免费版限制 | 30,000,000 CPU 毫秒/月；超出 $0.02/百万毫秒 |
| Durable Objects 房间请求 | 100,000 次/天 | 1,000,000 次/月；超出 $0.15/百万次 |
| 房间运行时间 | 13,000 GB·秒/天 | 400,000 GB·秒/月；超出 $12.50/百万 GB·秒 |
| SQLite 读取 | 5,000,000 行/天 | 25,000,000,000 行/月；超出 $0.001/百万行 |
| SQLite 写入 | 100,000 行/天 | 50,000,000 行/月；超出 $1/百万行 |

付费最低 $5/账户/月，包含额度不另外收一次套餐费。超过包含额度会产生额外账单；不是付费后每天固定有若干次，也不是最低 $5 包含无限服务。静态资源请求免费。DO 的 WebSocket 入站消息按 20:1 计费，官方分析原始消息数未折算；本项目卡片将消息数除以 20 后估算。统计为账户级，包含新旧站点及其他 Worker 的使用量。

每日限制在 UTC 00:00，即北京时间 08:00 重置。SQLite 总存储免费限制为 5 GB，本轮首页未展示总存储；KV 统计缓存还有自己的免费限制（每日 100,000 读取、1,000 写入），不是每日 10 万次请求的另一份可相加额度。

来源：
- https://developers.cloudflare.com/workers/platform/pricing/
- https://developers.cloudflare.com/durable-objects/platform/pricing/

# 接通自动统计

1. 在 Edge 打开 https://dash.cloudflare.com/profile/api-tokens 并登录。
2. 创建自定义 API Token，名称例如 `wudou-quota-read`。
3. 权限仅选 **Account → Account Analytics → Read**；账户资源只选当前 BP 的 Cloudflare 账户。不需要部署、写入、付款权限。
4. 把令牌填入本机项目 `.env.analytics` 的 `CF_ANALYTICS_TOKEN=` 后面。该文件已被 Git 忽略，不会上传或放入网页。不要把令牌发到聊天中。
5. 执行 `npm run quota:setup`。脚本先验证读取能力，再把令牌保存为 Cloudflare Worker Secret。运行 `npm run quota:setup` 不会升级付费套餐。Cron 每 5 分钟刷新账户统计到 KV，Pages 仅读缓存。

尚未安装只读令牌时，部署时可用 `npm run quota:refresh` 上传一次官方统计快照，首页明确标注“自动更新尚未接通”。旧快照不会被描述为实时余额。安装令牌之后，下一次 Cron 会改成自动统计。

每个打开首页的浏览器请求一次 `/quota`，停留首页时每 5 分钟刷新一次。建立连接前，若最近超过 1 分钟未读取，则再核查一次。统计端点是 Functions 请求，会计入每日额度。缓存减少官方 API 调用和 KV 读取，不能让 Functions 请求免计费。

统计有采样及上报延迟，剩余为估算值。确认任一展示资源达到免费限制，或收到平台明确的每日额度耗尽错误后，本浏览器会停用创建、加入、自动恢复和持续重试直到下一个 UTC 日。本机演练保持可用。普通 429、网络故障、CPU 超时不会被误判成每天额度耗尽。服务无法给出统计时显示未知，不伪造余额；仅凭统计延迟无法保证提前挡住所有额度耗尽请求。
